## 📑 Curriculum Summary (KBCNMU NEP-2020)

### 🔹 Second Year BCA (Semester-III & IV)
- **Theory Courses**:
  - `CA-211`: Data Structures (DSC-7) - 2 Credits (20 CA + 30 UA)
  - `CA-212`: Python Programming (DSC-8) - 2 Credits (20 CA + 30 UA)
  - `CA-215(A)`: Fundamentals of Accounting / `CA-215(B)` Graph Theory (MIN-2)
  - `CA-217`: Ethical Hacking (VSC-3)
- **Practical Courses**:
  - `CA-213`: Practical based on Data Structures (using C++) (DSC-9)
  - `CA-214`: Practical based on Python Programming (DSC-10)
  - `CA-216(A)`: Practical on Tally / `CA-216(B)` Practical on Graph Theory (MIN-3)
  - `CA-218`: Field Project (FP-1)
