## 💡 How Students Can Use This Repository

### 1. View & Copy Code Directly in Browser
- Click on your class folder in the table above.
- Navigate to the relevant Unit or Practical folder.
- Click any `.py`, `.php`, or `.cpp` file to view the syntax-highlighted code.
- Click the **"Copy raw contents"** button at the top-right of any file to copy code.

### 2. Download a Single Code File
- Open the code file on GitHub.
- Click the **Download raw file** button (or right-click `Raw` and select *Save Link As...*).

### 3. Clone / Download the Entire Repository (ZIP)
- Click the green **`<> Code`** button at the top right of this repository page.
- Select **`Download ZIP`** to get all code files on your computer.
- Or using Git in your terminal:
  ```bash
  git clone https://github.com/TahirMansuri/BCA-Codes.git
  ```

## ⚙️ Environment Setup Guidelines for Students

- **Python (SYBCA)**: Install [Python 3.12+](https://www.python.org/downloads/) & [VS Code](https://code.visualstudio.com/).
- **PHP (TYBCA)**: Install [XAMPP Server](https://www.apachefriends.org/) (Apache + MySQL) and place scripts in `htdocs`.
- **C++ (FYBCA)**: Install [MinGW-w64 GCC Compiler](https://www.mingw-w64.org/) or [Code::Blocks / VS Code with C++ extension](https://code.visualstudio.com/).

## 📢 Instructions & Best Practices for Students
1. **Understand before typing**: Do not simply copy-paste code. Read the inline comments explaining the logic.
2. **Execute on your machine**: Always run the code on your own machine and test with custom inputs.
3. **Star the Repository**: Click the ⭐ **Star** button on the top right corner of GitHub to keep this repository easily accessible in your GitHub bookmarks.
