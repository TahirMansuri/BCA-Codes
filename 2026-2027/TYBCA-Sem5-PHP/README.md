## 💻 How to Run PHP Codes on Local Machine

1. **Install XAMPP Server** from [Apache Friends](https://www.apachefriends.org/).
2. Start the **Apache** (and **MySQL** if needed) module from the XAMPP Control Panel.
3. Place this subject's code folder inside:
   ```text
   C:\xampp\htdocs\TYBCA-PHP\
   ```
4. Open your browser and navigate to:
   ```text
   http://localhost/TYBCA-PHP/Unit-01-PHP-Basics/01_hello_world.php
   ```
