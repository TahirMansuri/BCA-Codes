## 💻 How to Run PHP Programs Locally

1. Install **XAMPP** and start the **Apache** web server.
2. Clone/place this folder inside `C:\xampp\htdocs\`.
3. Open browser and visit: `http://localhost/BCA-Codes/2026-2027/TYBCA-Sem5-CA-317A-Web-Technologies-I/Practicals/Lab-Programs/practical_01_php_intro.php`
