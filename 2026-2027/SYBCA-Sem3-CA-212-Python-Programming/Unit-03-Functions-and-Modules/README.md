# 📙 Unit 3: Python Functions and Modules

## 📑 Syllabus Coverage

- **Functions**: `def` keyword, Calling functions, Positional / Required arguments, Default arguments, Variable-length arguments (`*args`, `**kwargs`), Local vs Global scope, Return values.
- **Advanced Functions**: Anonymous Lambda functions, Mapping functions (`map()`, `filter()`).
- **Modules**: Creating custom modules, `import` statement, Built-in standard library modules (`math`, `random`, `os`, `sys`, `datetime`).
