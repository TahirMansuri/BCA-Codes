## 📌 Assignment Questions

### Question 1: Temperature Converter
- **Problem**: Write a Python program to convert temperature from Celsius to Fahrenheit and vice versa using standard formulas:
  - $F = (C \times 9/5) + 32$
  - $C = (F - 32) \times 5/9$
- **File**: `q1_temperature_converter.py`

### Question 2: Employee Gross Salary Calculator
- **Problem**: Write a Python program to calculate the Gross Salary of an employee.
  - Input: Basic Salary
  - Allowances: HRA = 20% of Basic, DA = 40% of Basic
  - Gross Salary = Basic Salary + HRA + DA
- **File**: `q2_gross_salary_calc.py`
