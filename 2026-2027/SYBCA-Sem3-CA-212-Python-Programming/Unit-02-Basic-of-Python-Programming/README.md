# 📗 Unit 2: Basic of Python Programming
**Course Code**: CA - 212 | **Lectures**: 08 L | **Marks Weightage**: 15 Marks

---

## 📑 Syllabus Coverage

- **Strings in Python**: String Literals, Multiline Strings, String Slicing & Indexing, Methods (`lower`, `upper`, `count`, `index`, `find`, `replace`).
- **Python Lists**: Creating, Accessing, Slicing, Traversing, Updating, Deleting, List Methods (`append`, `extend`, `insert`, `pop`, `remove`, `sort`).
- **Python Tuples**: Tuple Immutability, Operations (Concatenation, Repetition, Membership, Iteration), Tuple Methods (`count`, `index`).
- **Python Dictionaries**: Key-Value Pairs, Accessing, Updating, Methods (`keys`, `values`, `items`, `get`, `pop`, `update`).
