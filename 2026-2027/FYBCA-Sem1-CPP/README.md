## 💻 How to Compile and Run C++ Programs

1. **Compiler**: Install GCC (MinGW-w64).
2. Open terminal in the code directory:
   ```bash
   g++ 01_hello_world.cpp -o 01_hello_world.exe
   ./01_hello_world.exe
   ```
