## 💻 How to Run Python Codes

1. **Prerequisite**: Make sure [Python 3.x](https://www.python.org/) is installed and added to PATH.
2. Open terminal/command prompt in the program folder:
   ```bash
   python 01_hello_world.py
   ```
3. In **VS Code**, open the folder and press the **Run Code** button (▶️) or press `F5`.
