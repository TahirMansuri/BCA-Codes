## 🔍 Detailed Topic Breakdown

### 📘 [Unit 1: Introduction to Python](./Unit-01-Introduction-to-Python) *(07 L, 10 M)*
- **Introduction to Python**: History of Python, Need, Features of Python, Applications of Python.
- **Standard Data Types**: Basic, `None`, Boolean, Numbers, Type conversion Functions, Operators in Python, Operator Precedence.
- **Fundamentals of Python Programming**: Identifiers, Variables, Keywords, Comments, Expressions and Statements, Accepting Input (`input()`) and Displaying Output (`print()`).
- **Flow Control Statements**: Conditional Statements (`if`, `if-else`, `if-elif-else`), Looping Statements (`for`, `while`), `break`, `continue`, `pass` Statements.

### 📗 [Unit 2: Basic of Python Programming](./Unit-02-Basic-of-Python-Programming) *(08 L, 15 M)*
- **Introduction to String**: String Literals, Assigning String to Variables, Multiline Strings, String Operations (Index Operator, Slice Operator), Working with characters, String Methods (`lower()`, `upper()`, `count()`, `index()`, `find()`, `replace()`).
- **Concepts of Python Lists**: Creating, Initializing, Accessing elements, Traversing, Updating, and Deleting elements. List Operations: Concatenation, Indexing, Slices, Built-in List functions and methods (`append()`, `extend()`, `insert()`, `pop()`, `remove()`, `sort()`, etc.).
- **Introduction to Tuples**: Creating, Accessing, and Deleting Tuples. Tuple Operations: Concatenation, Repetition, Membership, and Iteration. Built-in Tuple functions and methods.
- **Introduction to Dictionary**: Key-Value pair concept. Creating, Initializing, Accessing, Traversing, Updating, and Deleting elements. Built-in Dictionary functions and methods (`keys()`, `values()`, `items()`, `get()`, `update()`, etc.).

### 📙 [Unit 3: Python Functions and Modules](./Unit-03-Functions-and-Modules) *(08 L, 15 M)*
- **Introduction to Functions**: Defining (`def`), Calling, Function Arguments (Required arguments, Default arguments, Variable-length `*args`/`**kwargs`), Scope of Variables (Local vs Global), Void functions vs Functions returning values.
- **Advance Function Topics**: Anonymous Functions (`lambda`), Mapping Functions (`map()`, `filter()`).
- **Introduction to Modules**: Creating custom modules, Importing modules (`import`, `from ... import`), Built-in standard modules (`math`, `random`, `datetime`, `os`, `sys`).

### 📕 [Unit 4: Object Oriented Concepts & Libraries](./Unit-04-OOP-and-Libraries) *(07 L, 10 M)*
- **OOP Terminology**: Creating Classes, Creating Objects, Accessing Attributes, Built-in Class Attributes (`__doc__`, `__name__`, `__module__`, `__dict__`).
- **Garbage Collection & Lifecycle**: Constructors (`__init__`), Destructors (`__del__`), Method Overloading (via default arguments/multiple dispatch), Method Overriding (Inheritance).
- **Python Libraries Ecosystem**:
  - Data Science & Math: `NumPy`, `Pandas`, `Matplotlib`, `Seaborn`
  - Machine Learning & AI: `Scikit-learn`, `PyTorch`, `pyBrain`
  - Web Development: `Flask`
